---
title: Contributing
description: How to contribute to Databasify.
---

Bug reports, fixes and documentation improvements are welcome. Read the full guide in [CONTRIBUTING.md](https://github.com/databasifylabs/databasify/blob/0.x/CONTRIBUTING.md).

In short:

- Small, obvious changes can go straight to a pull request. Features, new engines and larger changes need an issue first.
- Branch from `0.x` and open your pull request against `0.x`.
- Run the checks before you open a pull request: `php artisan test`, `vendor/bin/phpstan analyse`, `vendor/bin/pint` and `npm run check`.
- Commit messages follow Conventional Commits.
- Read the [architecture decision records](https://github.com/databasifylabs/databasify/blob/0.x/docs/adr/README.md) that touch the files you change.
